# RickMate 🚖

RickMate is a dynamic and user-friendly ride-sharing platform designed specifically for auto-rickshaws. The application helps users book auto-rickshaws in a few simple steps, share rides with others, and enjoy a seamless transportation experience.

Whether you're looking for a ride or want to offer a shared ride, RickMate connects drivers and passengers in real-time, providing a hassle-free solution for daily commutes.

---

## Features 🛺

- **Book a Ride:** Request an auto-rickshaw with ease through the mobile app.  
- **Ride Sharing:** Share your ride with others and save on transportation costs.  
- **Live Map:** Track the location of nearby auto-rickshaws in real-time.  
- **Driver Profiles:** View the driver’s details, rating, and history before booking a ride.  
- **Fare Estimation:** Get an accurate fare estimate before confirming your ride.  
- **Multiple Payment Options:** Pay for your ride using cash or in-app payment methods.  
- **Ride History:** Keep track of past rides, payments, and booking details.  
- **User Ratings:** Rate your driver and share feedback to improve service quality.  
- **Admin Panel:** Easy-to-use web dashboard for managing drivers, users, and ride requests.

---

## Technologies Used 🖥️

- **Flutter:** Used to build the mobile app for cross-platform support.  
- **Laravel:** The backend framework that handles user authentication, ride management, and real-time data updates.  
- **Google Maps API:** For live location tracking and route mapping.  
- **Socket.IO:** For real-time communication between the app and the server.

---

## How It Works 🔄

1. **User Registration:** New users sign up and authenticate via the app.  
2. **Book a Ride:** Users can search for nearby available rickshaws and request a ride.  
3. **Driver Accepts Ride:** The driver gets a notification and can accept or reject the booking.  
4. **Ride Sharing:** If there are multiple users, the app offers the option to share the ride for cost savings.  
5. **In-App Tracking:** Both drivers and users can track each other’s locations in real-time.  
6. **Payment & Rating:** Upon reaching the destination, the user makes the payment and rates the driver.
